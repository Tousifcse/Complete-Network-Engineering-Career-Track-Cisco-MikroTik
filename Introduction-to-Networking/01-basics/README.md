# 01. Basics of Networking

## What is a Computer Network?
A **computer network** is a collection of two or more devices (computers, servers, phones, printers, etc.) connected together to share resources, data, and communication.

## Why Do We Need Networking?
- **Resource sharing** – printers, files, internet connection
- **Communication** – email, messaging, video calls
- **Data sharing** – transferring files between systems
- **Centralized management** – easier to manage data and security from one point
- **Cost efficiency** – shared resources reduce hardware costs

## Key Terminology

| Term | Meaning |
|------|---------|
| Node | Any device connected to a network (PC, printer, router, etc.) |
| Host | A device that can send/receive data over the network |
| Server | A computer that provides services/resources to other computers |
| Client | A computer that requests services from a server |
| Bandwidth | The maximum data transfer rate of a network |
| Latency | The time delay for data to travel from source to destination |
| Packet | A small unit of data sent over a network |
| Protocol | A set of rules that governs data communication |
| IP Address | A unique numerical identifier assigned to each device on a network |
| MAC Address | A unique hardware identifier assigned to a network interface |

## Advantages of Networking
1. File and resource sharing
2. Centralized data storage & backup
3. Cost reduction (shared hardware/software)
4. Improved communication
5. Increased storage capacity

## Disadvantages of Networking
1. Security risks (hacking, viruses)
2. High setup cost initially
3. Requires network administrators
4. Dependency on network — failure can stop work
5. Complex to manage for large networks
