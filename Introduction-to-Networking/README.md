## 🎯 Purpose

This repository is meant as a beginner-friendly, well-organized set of notes for anyone studying **Introduction to Computer Networking** — whether for a course, a presentation, or self-study.

## 🗂️ Structure

Each folder contains a `README.md` with notes on that specific topic, written in simple language with diagrams (where applicable) and comparison tables.
